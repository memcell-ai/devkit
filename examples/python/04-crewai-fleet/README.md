# CrewAI Fleet Coordination with MemCell (Python)

Demonstrates multi-agent coordination using CrewAI principles alongside MemCell:

1. Seeds shared editorial policies and enforced fact-checking guards into a shared workspace.
2. Synchronizes disparate agent roles (Researcher, Writer) against the same authoritative epistemic context.

---

## Running this Example

```bash
export MEMCELL_TOKEN="mc_pat_..."
export MEMCELL_WORKSPACE="acme/editorial-crew"

python main.py
```
