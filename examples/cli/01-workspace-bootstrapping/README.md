# Workspace Bootstrapping (CLI)

Demonstrates how to script MemCell workspace initialization and memory seeding via the `memcell` CLI:

1. Provisions a new workspace via `memcell workspace new`.
2. Connects the local directory with `memcell connect`.
3. Seeds initial operational guards and directives via `memcell remember`.
4. Inspects active configuration with `memcell status`.

---

## Running this Example

```bash
chmod +x bootstrap.sh
./bootstrap.sh
```
